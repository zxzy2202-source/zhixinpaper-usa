# Conversion Message

## Urgent buyer problem

A familiar roll name can hide a different width convention, OD, length, core, winding, grade, chemistry, or packing plan. The resulting mismatch creates printer failures, short-roll disputes, missing compliance evidence, and slow requoting.

## Primary promise

Turn an ambiguous request into a quote-ready specification before price comparison.

## Primary CTA

`Get a Specification-Based Quote`

## Qualification fields

Application, printer model, width, maximum OD or required length, core ID, paper grade, winding, mark or sensor, printing, packaging, quantity, destination, and any named exposure or document requirement.

## Supporting CTA

Request a sample after the device, dimensions, grade candidate, and test conditions are clear.

## Not-fit signals

- Single-roll retail purchases.
- Requests for an absolute durability, image-life, or compatibility guarantee without a named grade and test condition.
- Jumbo-reel commitments before converter and supply capability review.

## Friction handling

- Unknown size: send the printer model, current roll photo, or sample.
- Unknown compliance term: name the destination market and restricted substance.
- Unknown performance grade: describe the liquid, oil, abrasion, chemical, temperature, humidity, contact method, duration, and pass condition.
